GitHub Backup Manager

Private, personal-use backup automation. This utility is run locally by its owner to back up the owner's GitHub repositories to the owner's Google Drive.

Purpose

The local Windows application collects GitHub repository contents and associated metadata, encrypts backup snapshots with restic, and transfers those snapshots to the owner's Google Drive through rclone.

This public website provides OAuth consent information only. It does not request access tokens, process backup contents, or host private backup data. The application is not offered as a hosted service to others.

Google Drive access

Google authorization allows the owner's rclone installation to upload, list, retrieve, and manage backup files according to the granted Google Drive access scope. Access tokens stay in the owner's local rclone configuration. The encryption password is managed separately.

The owner may revoke the application's access through Google Account third-party access settings. This would prevent further cloud backups until authorization is restored.
