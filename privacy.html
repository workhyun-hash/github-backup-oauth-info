Privacy Policy

Application: GitHub Backup Manager
Last updated: October 20, 2026

Who operates this app?

This is a locally run, personal-use GitHub backup utility operated by its owner. It is not a hosted service offered to other users. Contact the support email shown on the OAuth consent screen with questions.

Data handled

The application retrieves the owner's selected GitHub repository contents and available metadata such as commit history, issues, and pull requests. With the owner's permission, rclone uses Google Drive access to create, list, read, and remove encrypted backup objects, subject to the granted scope and backup policy.

Where the data goes

Before upload, restic encrypts backup snapshots on the owner's PC. Encrypted data is uploaded to the owner's Google Drive. Google OAuth access tokens are kept in the owner's local rclone configuration; encryption passwords remain under the owner's control. This public website does not collect authentication credentials or backup contents.

Sharing and purpose

Data is used only for owner-authorized backup, restore and storage management. It is not sold or used for targeted advertising. Google and GitHub may separately process service and connection information according to their own policies.

Retention and deletion

Backups are retained according to the owner's chosen snapshot policy; automatic pruning starts only after recovery validation and explicit enabling. The owner can delete cloud backup objects and local credentials, or revoke OAuth authorization in their Google Account. Revocation by itself does not delete existing encrypted backups.

Public website

This static site has no embedded analytics, trackers, forms, or custom JavaScript. GitHub Pages may process ordinary hosting logs under GitHub's privacy policies.

Changes

This policy will be updated when the application's data handling materially changes.

Independently operated; not affiliated with Google or GitHub.
